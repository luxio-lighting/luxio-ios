# Luxio App Store screenshots

Five approved 1320 × 2868 PNGs, submitted with the iPhone 6.9-inch listing. Matching 1206 × 2622 derivatives in `iphone-6.3/` cover the 6.3-inch listing. See `app-store-status.json` for upload and ordering verification. Existing iPad screenshots are retained. Version 1.0.0 was submitted for review on 28 October 2026. This is the only retained iPhone marketing set; the current iPad captures are in `../screenshots/ipad-13/`.

The editable layouts are generated by `render.py`; run `./render.sh` on macOS with Google Chrome installed to reproduce the PNGs. The originals in `raw/` are actual simulator captures of the app, using demonstration devices and a deliberately nonfunctional Matter QR payload. Typography is Nunito, matching luxio.lighting, with the Luxio blue/mint/green gradient. Font license and download sources are in `fonts/`.

`MarketingScreenshots.swift` is an optional capture harness, kept outside the normal UI test suite. To recapture, run `fixture.ts` with Node and tsx from the repository, temporarily copy the Swift file into `UITests/`, regenerate the Xcode project, and run only `LuxioUITests/MarketingScreenshots`. Export its five `Marketing-*` attachments from the xcresult bundle into `raw/`. Remove the temporary test copy and regenerate the project afterward. Start a fresh fixture before each capture so the initial gradient is restored.

Revision 2 uses Cyberpunk, example network settings and a separate Matter view. During capture only, apply `capture-only.patch` to display the native Bluetooth icon for the Studio demo device; reverse it afterward. This presentation override is not included in the app source or release build.
